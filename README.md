## 🎮 What is LearnCode?

LearnCode is a **mobile game** that turns learning programming into an adventure. Level up, earn XP, keep your streak alive, unlock new languages, and eventually build your own levels for the community.

No boring tutorials. Just play, code, and level up. 👾

## 🌟 Features

- 🗺 **Level map** — progress through chapters like in Duolingo
- 🏆 **Ranks** — Novice → Student → Practitioner → Developer → Engineer → Master
- 🔥 **Daily streaks** — log in every day for XP multipliers
- ❤️ **Hearts** — lose one for each wrong answer
- 🏅 **Achievements** — unlock badges for milestones
- 💻 **Code editor** — unlocked at "Developer" rank, run code right on your phone
- 🛠 **Level builder** — create your own challenges for other players
- 🌈 **Neon theme** — dark cyberpunk UI with glowing accents

## 🛠 Tech Stack

- **Mobile:** [Flutter](https://flutter.dev/) (Android + iOS from one codebase)
- **Backend:** [Supabase](https://supabase.com/) (Postgres + Edge Functions)
- **Web:** [Next.js](https://nextjs.org/) (username recovery site)
- **CI/CD:** GitHub Actions (auto-build APK on every release)
- **Email:** Resend (recovery codes)
